# TechStore - TechLab

Aplicación de consola en Java para registrar, listar y gestionar productos, y crear pedidos con múltiples productos, descontando stock automáticamente.

## 🛠️ Tecnologías

- Java JDK 25+
- VS Code + Extension Pack for Java

## 📁 Estructura
src/com/techstore/
├── Main.java
├── exception/ → excepciones personalizadas
├── model/ → Producto, Bebida, Comida, Pedido, LineaPedido
├── service/ → ProductoService, PedidoService
├── ui/ → Menu, ProductoUI, PedidoUI
└── util/ → Validador, Consola
